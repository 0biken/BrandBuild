# Owner review: 20 live plans

Target: at least 16 of 20 plans (80%) score 4 or 5.

## How to run a review

1. Run a live plan for a business. Use a test workspace with the owner's real brand
   profile and verified facts, on a paid-tier key (see `docs/provider-contracts/gemini.md`).
   You can also use `cargo run --bin evals -- --provider gemini --only q-<brand>-1` and
   read the kept posts in the JSON report.
2. Give the owner the kept drafts. Ask: *"Would you post these with small edits or none?"*
3. Score the plan from 1 to 5:
   - 5: would post as is.
   - 4: small edits.
   - 3: needs real rewriting.
   - 2: mostly unusable.
   - 1: wrong or harmful.
4. Write down anything off-brand, wrong or unsafe. A made-up fact or price is an automatic 1
   and a bug report.
