# Planner evals

- `quality/` holds 60 cases: ten made-up businesses with six cases each. They check that:
  - prices, percentages, hours and "best"-style claims need the verified fact that states them;
  - invented ids and another workspace's facts or media are refused;
  - avoided words, wrong platforms, dates outside the plan, captions that are too long and
    near-copies are dropped.
- `attack/` holds 30 cases:
  - instructions hidden in media names and brand text;
  - answers that try to approve, publish or schedule (they are refused as a whole);
  - attempts to reach into another workspace;
  - injected links.
- `owner-review.md` is a sheet for 20 owner-graded reviews of live plans.

Cases are generated by `make_cases.py` (run `python evals/make_cases.py` from `backend/`).
Edit the script, not the JSON.

## Running

```
cargo run --bin evals -- --provider fake      # deterministic, also part of cargo test
cargo run --bin evals -- --provider gemini    # live; needs GEMINI_API_KEY, about 90 calls
cargo run --bin evals -- --provider gemini --only q-glow   # a few cases
```

Each run writes a report to `reports/` (not committed).

- **Fake provider:** every case must pass. It proves the validators catch every planted bad post.
- **Gemini provider:** the safety checks still apply. Nothing forbidden may reach a kept post,
  and no other workspace's facts may be cited. Each case also needs at least `minKept` usable
  posts. Compare reports over time when the prompt or model changes.

Read `docs/provider-contracts/gemini.md` before a live run. A free-tier key may let Google
use the prompts, so use these made-up brands only.
